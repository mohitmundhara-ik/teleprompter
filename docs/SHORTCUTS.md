# Keyboard shortcuts

Shortcuts never fire while the caret is in a text box, a text area, a select or
any editable region. The same list is available in the app under Settings.

| Keys | Action | Where |
| --- | --- | --- |
| `→` / `Page Down` | Next page | Both windows |
| `←` / `Page Up` | Previous page | Both windows |
| `Space` | Start or pause auto-scroll | Teleprompter |
| `↑` / `↓` | Scroll the script by hand | Teleprompter |
| `+` / `-` | Font size up and down | Teleprompter |
| `D` | Dark and light | Both windows |
| `M` | Mirror horizontally, for prompter glass | Teleprompter |
| `H` | Hide or show the controls | Teleprompter |
| `R` | Restart the script from the top | Teleprompter |
| `T` on the empty stage | Opens the teleprompter before a deck is loaded | Main window |
| `P` | Enter or leave present mode: the slide alone fills the tab, no controls | Main window |
| `F` | Full screen on this monitor | Both windows |
| `T` | Open or focus the teleprompter | Main window |
| `Escape` | Leave presenting or full screen, or bring hidden controls back | Both windows |
